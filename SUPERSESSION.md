# Does a memory know which version of a fact is current

Generated by `supersede.py`. Do not edit by hand.

Every corpus here asks about a record that does not change. A memory store is not used that way: a
fact is written, then rewritten, and the first thing its owner needs is the current value rather than
the one it replaced. `restart` and `forget` cover a record that is deleted; nothing covers a
record that is superseded, which is the ordinary case.

Every chosen package record is stored **twice**, as two records whose only difference is the version
string in the body, and each question asks with the description both carry. The current answer is the
later record.

## The predictions, written before the run

1. No subject scores above three quarters.
2. Subjects that return several results return both versions about as often as either one.
3. At least one subject scores below a quarter.

**The best subject puts the current record first on 55 of 72 questions, and 9 of the 11 subjects
never put it first once.** Every one of those returns the SUPERSEDED record ahead of the record that
replaced it, because the two bodies are nearly identical and nothing in either says which is later.

Across the whole table, 55 answers came from the superseded record and 549 returned both, which is
the honest description of what these systems do with a fact that changed: they have no notion of
which of two nearly identical records is later, and the text gives them none.

## What this does not settle

The two versions differ in the body and not in the record's name, so this measures *ranking* between
two candidates rather than storage semantics. A subject that overwrites a record on a repeated write
- which some of them do - would answer this trivially if the two writes used the same name; keeping
the names distinct is deliberate, because the question is whether recency is visible at all.

It also does not test a real update protocol. Asking a memory to revise a fact, and being able to
distinguish a revision from a second unrelated fact, is a capability none of these subjects claims and
the probe suite has never asked for.
